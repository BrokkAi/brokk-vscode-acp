# Support

For defects and feature requests, use the Brokk ACP issue tracker:

https://github.com/BrokkAi/brokk-vscode-acp/issues

Include the Brokk ACP version, VS Code version, operating system, selected ACP
agent, and relevant output from **View → Output → Brokk ACP**. Remove tokens,
credentials, prompts, and proprietary source before sharing logs.
