# Security

Brokk ACP launches coding agents that can request workspace file access and
terminal commands. Only use agents, registry URLs, and custom commands that you
trust.

Please report security vulnerabilities privately through BrokkAi's GitHub
security advisory form:

https://github.com/BrokkAi/brokk-vscode-acp/security/advisories/new

Do not open a public issue for an undisclosed vulnerability.
